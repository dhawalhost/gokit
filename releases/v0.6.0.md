# Gokit v0.6.0 Release Notes

`v0.6.0` is a major milestone release for `gokit`, delivering **6 new production-grade subsystems** (over 11,600+ lines of code) spanning cloud object storage, enterprise gRPC client/server, real-time WebSocket & SSE streaming, adaptive load shedding, dynamic configuration watchers, and notification engines.

Repository test coverage now stands at **91.1%** across 39 packages with clean race detection (`make test-race`).

## 🚀 What's New

### 1. Multi-Backend Object Storage (`storage`)
A unified object/blob storage abstraction supporting AWS S3, local disk/filesystem, and in-memory drivers:
- **Consistent API**: `Put`, `Get`, `Delete`, `Stat`, `List`, and directory traversal across all drivers.
- **Advanced Capabilities**: Pre-signed URLs (upload & download), streaming uploads, metadata tags, and byte-range reads.
- **Drivers**:
  - `s3.go`: Production AWS S3 / MinIO driver using AWS SDK v2.
  - `filesystem.go`: Local disk storage with automatic directory creation and atomic file writes.
  - `memory.go`: High-speed thread-safe in-memory driver for unit tests and local mock environments.

```go
store, err := storage.NewS3Storage(storage.S3Config{
    Bucket: "my-app-uploads",
    Region: "us-east-1",
})
url, err := store.SignedURL(ctx, "invoices/2026-001.pdf", 15*time.Minute)
```

### 2. Production gRPC Client & Server Suite (`grpc`)
Enterprise-grade gRPC infrastructure designed for microservices:
- **Server**: Pre-wired interceptor chains for panic recovery, Prometheus metrics, structured logging, request ID propagation, authorization, and OpenTelemetry metadata carriers.
- **Client**: Connection pooling, automatic keepalives, non-blocking asynchronous dial, client-side retry with exponential backoff, and circuit breaker hooks.
- **Error Mapping**: Idiomatic translation between internal domain errors and gRPC status codes (`codes.InvalidArgument`, `codes.NotFound`, `codes.Unauthenticated`, etc.).

---

### 3. Real-Time Streaming & WebSocket Hub (`streaming`)
High-concurrency streaming infrastructure for real-time web applications and IoT:
- **WebSocket Hub (`ws_hub.go`)**: Room/channel pub-sub architecture, multi-tenant isolation, automatic ping/pong keepalives, client connection tracking, and backpressure protection.
- **WebSocket Client (`ws_client.go`)**: Client session with auto-reconnection, write buffers, and message pumps.
- **Server-Sent Events (`sse.go`)**: Zero-dependency SSE stream handler supporting custom event types, replay IDs (`Last-Event-ID`), and periodic heartbeat frames.

---

### 4. Adaptive Latency-Based Concurrency Limiter & Load Shedder (`loadshed`)
Dynamic overload protection inspired by **TCP Vegas** and Netflix's **concurrency-limits**:
- **Why It Matters**: Solves the latency collapse problem where static rate limits fail when downstream dependencies slow down.
- **Gradient Limit Algorithm**: Dynamically computes capacity by comparing real-time RTT against `minRTT`:
  $$\text{gradient} = \frac{\text{minRTT}}{\text{sampleRTT}}$$
- **Priority-Aware Admission**:
  - `PriorityCritical`: Probes, auth, health checks (reserved +20% headroom).
  - `PriorityStandard`: Standard user traffic.
  - `PriorityLow`: Background tasks, batch scraping, analytics (early-shed).
- **Batteries-Included**: Drop-in HTTP middleware (`503 / 429` with `Retry-After`) and gRPC interceptors (`codes.ResourceExhausted`).

---

### 5. Dynamic Configuration Watcher & Hot Reloader (`config/watcher`)
Resilient configuration watching designed for modern container and Kubernetes environments:
- **Kubernetes ConfigMap Awareness**: Detects and handles atomic symlink rotations (`..data` symlink swap) used by Kubernetes volume mounts without missing updates.
- **Debounced Reloads**: Configurable debouncing to prevent thrashing during multi-file updates.
- **Provider Abstraction**:
  - `FileProvider`: File and directory watching via `fsnotify` with symlink target resolution.
  - `PollingProvider`: Remote HTTP/API polling with ETag / checksum validation.
  - `MemoryProvider`: In-memory dynamic updates for testing and simulated runtime reconfigurations.

---

### 6. Notifications & Multipart Email Engine (`notify`)
Production notification subsystem for transactional emails and SMS:
- **Multipart RFC-5322 MIME Builder**: Generates compliant email payloads with `multipart/alternative` (`text/plain` + `text/html`) and `multipart/mixed` base64 attachments with 76-character line wrapping.
- **Template Engine**: Dynamic subject, text, and HTML compilation using `html/template` with built-in helpers (`upper`, `lower`, `title`, `trim`, `now`, `formatDate`) and custom `template.FuncMap`.
- **Production SMTP Driver**: TLS & STARTTLS negotiation, plain auth, connection timeouts, and custom dialers.
- **Testing Driver (`MemorySender`)**: Thread-safe in-memory email and SMS sink for zero-network testing with inspection helpers (`FindEmailByTo`, `LastEmail`).
